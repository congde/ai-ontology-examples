# 第 2 章 检查查询对象、工具和权限

实现为 [check_read_proposal.py](check_read_proposal.py)。在本目录用 Python 3.11 或更高版本运行，无需安装第三方库。

```text
python -X utf8 check_read_proposal.py
```

原样运行应输出“四项查询边界检查通过”。本次任务只允许读界面选中的 A-001。

| 模型提议与授权条件 | 预期 |
|---|---|
| 查询 A-001，账号可查 | 允许 |
| 查询另一个账号也能访问的 A-002 | 拒绝，超出本任务 |
| 对 A-001 提议创建工单 | 拒绝，当前只读 |
| 查询 A-001，账号无读取资格 | 拒绝，超出权限 |

再取三个独立脚本副本，分别移去工具名、当前对象和可读范围检查。对应断言应报告失败。每次从原稿出发，只动一项，才看得出是哪项约束起作用。
