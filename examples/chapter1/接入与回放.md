# 告警沙箱、模型回放与系统接入

第 10.4.2、11.2、11.4.1、11.4.2、12.2 和 12.4.1 节的上机步骤共用本页。沙箱脚本使用 Python 3.11 或更新版本、标准库和本地 SQLite。执行命令之前，以 `python --version` 核对版本，将 [repair_agent.py](repair_agent.py) 复制到一个新的可写目录。运行期间应留在该目录。再练一遍完整沙箱时换用新的空目录。

## 顺序验证草稿、回执、批准和重发

```text
python -X utf8 repair_agent.py propose
python -X utf8 repair_agent.py receipt R-001
python -X utf8 repair_agent.py approve R-001
python -X utf8 repair_agent.py receipt R-001
python -X utf8 repair_agent.py approve R-001
python -X utf8 repair_agent.py receipt R-001
```

- 第一次提出申请得到 R-001，状态为“待审批”。默认回放提出读证请求 `{"tool":"read_evidence","alarm_id":"A-001"}`。证据中的 `alarm` 为 09:00 告警，`observation` 为 09:10 的运行观测，`repair_result` 为 `null`，表示本次合成材料缺少维修结论。
- 第一次查回执的 `status` 是“尚无工单回执”。批准后，查到同一申请对应 W-001，`result` 为“已创建”，工单 `status` 为“待派工”。
- 重复批准及查回仍应指向 W-001。业务库保存在 `repair_demo.sqlite3`，重新启动程序仍可查回同一目录中的记录。

## 可选的模型测试

先完成回放，再使用获准的 Chat Completions 测试服务。向当前进程注入 `MODEL_CHAT_URL`（完整地址）、`MODEL_NAME`（服务认可的模型名）和该服务如需要的 `MODEL_API_KEY`。测试数据是合成告警和工具约定。采用另一个空目录运行：

```text
python -X utf8 repair_agent.py propose --live
```

程序读取 `choices[0].message.content` 中的 JSON，校验后才处理本地数据；成功时回报 `mode` 为“模型接口”。环境变量缺失、服务拒绝、输出无法解析或提议越界时停止。保留此次执行模式与实际模型、工具版本。使用获准测试配置并控制可发的数据范围。

## 企业只读联调样本

以下仅约定隔离测试环境的接口与合成输入。示意主机是 `https://maintenance-test.example.com`。在部署配置中填写实际服务地址、允许的访问范围与每次调用的超时，凭据由部署平台注入。以只读账号分别验证三个查询，再接入 `read_evidence`。

| 示例路径 | 合成测试的取值与时点 | 应核对的取得状态 |
|---|---|---|
| `GET /alarms/A-001` | 主轴振动告警、09:00、E-001、原记录标识或版本 | 查询成功，设备映射与原告警相符 |
| `GET /devices/E-001/observations/latest` | 09:10 的运行观测、观测时点和记录标识 | 读取时点另记，`running` 只映射到设备运行状态 |
| `GET /maintenance-results?alarm_id=A-001` | 测试材料没有 A-001 的维修结论 | 成功且覆盖 A-001 的空结果、超时、访问受限分别证明 |

## 企业办理联调样本

在隔离环境配置 `POST /work-orders` 和 `GET /work-order-requests/R-001` 两条示例路径，实现创建与按原申请查回。部署时配置实际服务地址、调用身份、授权和单次超时。模型、审批、执行凭据分别用于各自的服务。

1. 仅在测试身份和测试数据库中提交已获准的 R-001，附 A-001、E-001、获准动作、审批引用与草稿版本。
2. 核对接收端关于同一厂区与执行身份的去重规则，登记编号、参数和有效期。按 R-001 查回对应工单与办理状态。若只有受理记录，则继续查原申请。
3. 逐次模拟工单已保存但回执丢失、已经受理但未创建、查询无权、超过重试期限、改参数重提。保留实际调用、查回结果及下游工单数量。工单已经保存的超时例应按 R-001 查回 W-001；其他分支须依据约定如实保留处置状态。

企业系统的授权、接口和回查方式，以实际接入测试材料为准。
