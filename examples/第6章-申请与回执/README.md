# 第 6 章申请与回执

这个练习对应第 6.5 节。程序用内存记录模拟工单服务，检查批准、授权、创建、反查、重复提交和请求内容冲突。当前教学代码只用告警号代表请求内容。

在本目录用 Python 3.11 或更高版本运行，无需安装第三方库。

```text
python -X utf8 check_work_order_lifecycle.py
```

成功时输出“批准、写入、反查、重试和冲突检查通过”。测试对照包括以下几项。

- 无批准或无授权时，工单数量均为零。
- 获准的 R-001 首次提交后建立 W-001，状态为“待派工”。
- 相同内容按 R-001 重试，应取得同一份 W-001 回执，工单仍只有一张。
- 就算模拟的批准与授权检查通过，同号申请改指 A-002 时也不创建第二张单。

可以复制脚本，在副本中删除返回已有回执的 `return existing` 一行。运行时重试结果将与 W-001 不同，原断言应失败。正文中反查超时的情况供纸面走查。真实系统还需测试持久化、完整请求内容、权限和并发。
