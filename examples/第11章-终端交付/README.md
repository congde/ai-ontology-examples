# 终端交付核查与交班

本示例对应第11章表 11-9。教学输入为同一客户的一个订单行，三份汇总属于同一批，已排除退货和重复记录。把同目录的三份程序复制到一个独立练习目录，进入该目录，使用 Python 3.11 或更新版本逐项运行。

```sh
python -X utf8 delivery_check.py
python -X utf8 delivery_test.py
python -X utf8 delivery_handover.py
```

第一份输出字典，其中 `unaccepted` 为10，表示未验收台数；`waiting` 为2，表示已到待验台数；`not_arrived` 为8，表示尚未到货台数。`sources` 列出三个输入量的来源。

第二份应打印正常的10、2、8和明确零验收的20、12、8；缺少资料、数量倒挂、重复汇总、范围串用四行分别给出退回理由。实际结果与任一预期不符时，脚本以非零退出码停止。

第三份接受带证据的正常候选，退回分类错误、额外日期、旧批次和超出字段范围的候选。用新建的 `delivery-handover-output` 目录里的 `candidate-review.json` 和 `handover.md` 核查结果。再次运行第三份时，把这三份程序复制到另一个练习目录，以便并排保存两轮输出。

工具只在已给定的客户及订单行内复算教学习题。向其他单位使用时，来源要能定位到权限允许的原始记录，并由实际接手岗位确认。
