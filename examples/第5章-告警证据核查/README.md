# 第 5 章告警证据核查

这个练习对应第 5.2.2 节。程序先用类别层级确认数控加工中心属于设备，再核对一份维修结论是否属于 A-001 并已经确认。

在本目录用 Python 3.11 或更高版本运行，无需安装第三方库。

```text
python -X utf8 check_alarm_evidence.py
```

成功时输出“设备类型和告警结论的四种检查通过”。

| 提交给 A-001 的材料 | 本节所检查的条件 | 可以采取的下一步 |
|---|---|---|
| 没有结论 | 暂停 | 按 A-001 补查 |
| A-002 的已确认结论 | 暂停 | 核对归属，按 A-001 重新取证 |
| A-001 的未确认结论 | 暂停 | 将已有结论交给有权岗位确认 |
| A-001 的已确认结论 | 通过本项检查 | 核对结论内容、操作许可及其他办理条件 |

可以复制脚本，在副本中只将反例里的结论归属改为 A-001。再次执行时，原来预期拒绝错单的断言将失败。这样可以核对该用例是否真正区分了两次告警。
